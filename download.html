Install in Chrome

  1. Download the extension ZIP above. GitHub's automatic Source code ZIP contains this public website, not the built extension.
  2. Extract it into a permanent folder such as Documents / Receipt Assistant.
  3. In the same Chrome profile you use for Mail, open chrome://extensions.
  4. Turn on Developer mode, then choose Load unpacked.
  5. Select the extracted folder containing manifest.json.
  6. Pin Receipt Assistant, open Mail and allow access to the configured workspace hosts. Check Settings if your ministry uses different addresses.
  7. Sign in to eOffice, launch the eFile module and wait for its inbox. Return to the assistant and choose Check again.

Keep the extracted folder in place. Office-managed Chrome may restrict manual installation or required permissions; do not bypass organisational policy.

Prepare a receipt

Open an email, choose the source message if asked, select Prepare receipt, edit the subject if needed, and choose the PDFs to include. Email only, Email with attachments and Attachments only all use the automatic eOffice upload and Generate flow.

Creating a receipt is a real action in your configured eOffice service. If an outcome is uncertain, check eOffice before starting again.

Mail app window

The standalone Chrome mail app uses one reusable companion. Arrange beside mail tiles it next to Mail; Restore layout releases the arrangement. Hide assistant keeps your choices, and clicking the extension brings that same window back. Normal Chrome tabs use the native side panel.

Update manually

Wait for receipt preparation to finish, close the assistant and extract the newer ZIP into the same permanent folder. On chrome://extensions, click Reload, then refresh Mail and eOffice. Disable older duplicate copies. Unpacked builds do not receive Web Store automatic updates.

Office network and NIC VPN

Settings save separate Office network and NIC VPN / home electronic receipt addresses, with one selected connection and shared Mail settings. Select the connection and Save settings before preparing a receipt. Connect to NIC VPN yourself when required, sign in to eOffice and launch eFile. Session checks and receipt creation follow the selected address.

PDF recovery in v0.21.11

Supported printable annotations are flattened automatically. If a PDF is protected, damaged, signed, interactive, contains embedded documents or exceeds a limit, the assistant explains the issue and identifies the affected file when possible. Review your PDF choices or explicitly exclude that file; your edited subject is retained. No file is silently skipped and no receipt is submitted by exclusion.

Password-protected PDFs require an authorised printable copy or exclusion. The extension does not ask for or store PDF passwords. Word, Excel and PowerPoint conversion remains unavailable.

What is included

The download contains the built extension only. Word, Excel and PowerPoint conversion is not available. Compatible Government Mail/eFile interfaces and authorised accounts are required; changing a workspace URL does not add support for a different application.
